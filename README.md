# Adaptive Preregistration for Model-Based Research

[![](https://zenodo.org/badge/246194109.svg)](https://zenodo.org/doi/10.5281/zenodo.10807029)

## About

This repository provides the source-code for [a practical guide to implementing *Adaptive Preregistration* for Model-Based Research](https://egouldo.github.io/EcoConsPreReg/) that accompanies the paper:

> Gould, E., Jones, C.S., Yen, J.D.L., Fraser, H.F., Wootton, H., Good, M., Duncan, D.H., Wintle, Bonnie, C., Rumpff, L. (in prep., 2026) "But I can't preregister my research": Improving the reproducibility and transparency of ecological modelling with adaptive preregistration.[^1] 

The guide provides background on researcher degrees of freedom and the risk of questionable research practices in model-based research, arguing that preregistration can improve the reproducibility and transparency of ecological modelling. The main components of the guide include an overview of adaptive preregistration, a practical guide on implementing it using *git* and *GitHub*, as well as a template that can be used to preregister ecological modelling studies.

The template and adaptive preregistration methodology were tested and refined using a case study of environmental flows modelling in Victoria, Australia, led by Chris Jones and Jian Yen at the Arthur Rylah Institute for Environmental Research[^2]. The data and code for that project are located at [https://github.com/egouldo/VEFMAP_VEG_Stage6](https://github.com/egouldo/VEFMAP_VEG_Stage6).
